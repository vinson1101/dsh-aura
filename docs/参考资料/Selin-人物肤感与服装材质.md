## 原文要点

作者用六组人物图说明如何描述受光后的局部细节。以下为归纳。

| 部位或材质 | 画面里应当看见什么 |
| --- | --- |
| 面颊和下颌 | 窗光下隐约可见细小毛孔，下颌轮廓有浅淡绒毛。 |
| 面部高光 | 鼻尖或下唇中央带一点亮光，面颊大面积呈哑光。 |
| 粗针织和棉麻 | 侧光能显出纱线和织纹，亮部柔和。 |
| 深色绒面 | 绒毛吸光，暗部深，转折处仍能辨认衣服的轮廓。 |
| 厚真丝 | 布料垂落形成有重量感的褶皱，柔亮的光带沿褶皱延伸。 |
| 碎发和薄纱 | 侧后方的光透过发梢和纱边，脸部仍清晰。 |

## Aura 半身定妆照的用法

下一次测试可沿用已确认的正面短发照，只改一句光线描述。例如「柔光从侧前方照来，双颊白里透红，近看有细微肌理，下唇中央有一小处柔和反光」。与母图同尺寸对照肤色、唇形和脸部轮廓，再决定是否采用。换装时按实际布料选词，奶白薄开衫侧重细密织纹与边缘透光程度，黑色修身上衣侧重暗部裁片轮廓。

文章讨论静态图像。若用作视频首帧，需另查说话和停顿期间唇部亮点是否跳动、短发边缘是否闪烁。本条只作后续参考，尚未在 Aura 上实测。
