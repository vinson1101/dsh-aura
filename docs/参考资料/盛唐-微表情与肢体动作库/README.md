## 本轮 H3 讲话候选

从 warm_welcome 取柔和笑眼、看镜头及自然呼吸；为符合用户反馈，去掉例行点头和逐词提眉。用 Wan 回答首帧作首尾参考，补充脸宽、短发、唇形、服装、肤色及棚景约束。请求 10 秒、768P；交付无声画面 10.125 秒，24 fps。抽帧可见中段有露齿和圆唇，结尾回到轻笑；与参考图同位置的顶部两角背景，逐帧 RGB 中位色最大通道差不超过 4/255。该项只衡量取样背景，不能证明任意回复的口型同步。

**背景基准更正。** 上述 4/255 描述 H3 跟随实际输入的 Wan 首帧的程度。原始背景基准是项目中的《半身定妆-脸型妆容与短发.png》。在三图相同归一化位置（横向 3.5%–12%、纵向 5%–12%），原定妆照、Wan 首帧、H3 第 5 秒的背景 RGB 中位值分别为 (64,62,66)、(55,59,56)、(53,58,55)。Wan 首帧已从紫灰偏到绿灰。现有片可沿用；后续正面姿态可以另有参考，背景颜色、明暗、纹理与肤色始终用原定妆照直接比对。[三图对照](背景三图对照.jpg)
