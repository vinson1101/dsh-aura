## 来源摘要

提示词将主体、场景、表演、音乐、镜头、分段动作、画质和避免项分开。强调放松、短暂微表情和动作间停顿，允许参考图只约束外观。目标是多镜头自拍，包含托腮、伸手、手机运动、音乐及未完成动作的截断收尾。

## Aura 可采用的规则（本项目适配）

1. **动作与安静交替。** 一条互动里不连续安排好几个明显动作；小表情出现后允许停留。常态待机不能被改成连续表演。
2. **用关系解释表情。** 描述她像在面对熟悉的人，而不是只要求“可爱”。对 Aura 可以具体为：注意到用户，短暂露出会意的笑，再恢复平静关注。
3. **笑意有起落。** 微笑不应从首帧持续到尾帧。嘴角、眼神逐渐变化，再自然放松；灿烂笑是独立情绪素材，不要求所有动作都露齿。
4. **重视接触与身体反应。** 手、头、肩与衣服应该协调，但不要因参考帖有托腮就强加给其他动作。托腮本身会改变脸颊轮廓，若未来采用，要区分合理受压与身份漂移；本轮不增加托腮制作。
5. **靠近由身体完成。** 固定机位下通过上身前倾和重心变化形成距离变化，不用数码变焦或单独拉长脖子。探镜头沿用已有草案的一次靠近与回位。

## 不能原样带入 Aura 的内容

| 原帖的创作选择 | 与 Aura 的冲突 | Aura 的替代约束 |
| --- | --- | --- |
| 参考图不固定首帧和构图 | 起始姿态、人物大小难以与待机对应 | 参考图负责身份，实际首尾输入负责进出姿态；两种控制明确区分 |
| 多段跳切、不同机位 | 当前正在解决的就是人物瞬移和画幅突变 | 单个互动保持一镜到底、固定机位与连续身体运动 |
| 手碰手机、临时倾斜、曝光变化 | 容易制造背景和肤色跳动 | 固定镜头、曝光、白平衡和棚景；通过人物表演增加自然感 |
| 暖色提亮、轻度美颜、微醺风格 | 可能改变已确认肤色和人物气质 | 沿用现有角色；不默认增加醉意、滤镜或肤色提亮 |
| 动作未结束即截断 | 回待机时速度与姿态接不上 | 动作先完成，回到待机锚点附近并稳定后才结束 |
| 音乐及现场环境声 | 会干扰 Aura 的真实收音和回答 | 无声互动移除音轨；不按背景音乐强制动作节拍 |

## 对下一条提示词草案的具体补充

沿用 [H3 微动作规则与探镜头草案](H3-生活化微动作提示词规律-20261125.md)，增加“表情不持续营业，完成动作后允许平静停留”；但不叠加本帖的拨弄手机、托腮、跳切和音乐。不把每份参考帖中的动作全部拼成一个视频。

采用提示词前先写清用途：短视频可以允许开放式结尾，Aura 可复用互动必须能返回待机。对前者有效的写法不等于对后者有效。
