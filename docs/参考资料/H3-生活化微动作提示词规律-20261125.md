# H3：生活化微动作提示词与 Aura 的适配

记录日期：2026-11-25（Asia/Shanghai）。[0xmomonifty 原帖](https://x.com/0xmomonifty/status/2125402675227566567)。已读取完整文字，通过公开镜像获取示例并每秒抽帧检查约 15 秒视频；未验证作者实际提交参数、失败次数或后期处理，不能认定效果完全由提示词决定。

## 来源摘要与观察

作者采用人物参考图，并按时间描述同一连续自拍中的视线、整理头发、身体后靠、微笑靠近及收尾，另规定质感、声音与禁止项。抽帧可见视线移开后回看、靠近时笑意变化和近景停留。提示词允许手机晃动、对焦及曝光变化；这种审美目标与 Aura 固定棚景不同。

## 我们需要改进什么

对照本项目上一条 [实际转身提示词](../../assets/previews/短发直播测试/H3-待机同帧转侧身-20261125/prompt.txt)，原提示并非完全没有细节：已写入人物锚定、固定机位、单次转身、时间和首尾同图。缺口是约束多、表演关系少；“轻微俏皮”“自然呼吸”仍抽象，眼神、笑意和身体如何接续没有充分表达。也不能为了细腻而给每秒塞一个动作。

以下为 Aura 的编写规则，是从案例中得到的本项目方案，不是作者对模型能力的保证。

| 编写项 | Aura 的执行规则 | 检查点 |
| --- | --- | --- |
| 参考依据 | 指定实际输入的待机帧；列出脸型、短发刘海、妆容、肤色、服装、棚景与机位的识别特征 | 提交的参考图必须与文案一致，不能拿旧侧身图充当正面锚点 |
| 动作缘由 | 先给角色一个简单意图，如看清对方、注意到招呼；再写可见动作 | 不只堆“自然、可爱、灵动”形容词 |
| 联动过程 | 描述视线变化如何带出笑意，重心如何带动肩颈；动作可以略有先后 | 避免只有脖子伸长、脸放大或嘴角独动 |
| 一条一事 | 一段只完成一个主要互动，其余细节为它服务 | 不为了丰富强加拨发、转身、挥手等多个主动作 |
| 时间与安静 | 按准备、展开、短暂停留、回位写节奏，允许自然静止和不规则眨眼 | 不规定每隔几秒点头、每段固定眨两次 |
| 微表情 | 用可见的眼睑、嘴角、唇部放松程度描述情绪幅度 | 灿烂笑与平静待机分开，不能每条都强制露齿 |
| 肤感与材料 | 在参考光线下保持已有细微纹理和局部高光 | 不重新指定暖色滤镜、通体发光、强柔焦或磨皮 |
| 镜头与人物运动 | Aura 固定机位；探镜头靠人物身体前倾实现 | 不通过变焦、自动曝光或手机晃动制造“真人感” |
| 结束条件 | 回到输入帧的姿态、大小和画面位置，安静停留后退出 | 首尾同帧仅是条件，仍需检查真实输出和相邻待机帧 |
| 声音 | 无声互动成片移除音轨 | 不把示例的呼吸、衣料声混进 Aura 收音或回答 |

## 下一条探镜头的提示词草案（未提交、未生成）

用途：从当前正面平静待机出发，做一次带轻微俏皮感的靠近，再回正面待机。输入采用已校正待机视频选定的同一帧作为首、尾帧；原定妆照用于输出核对。如接口不能同时接受额外参考图，不声称已额外输入。

> 连续的十秒固定机位半身镜头。画面中的成年女性就是输入图中的同一人：保持原有细长脸型和下颌线、五官比例、短发轮廓与刘海、妆容、自然白里透红的肤色、黑色方领长袖及银色项链。沿用输入图的灰紫棚景、柔和光线、机位和初始构图，不重新设计人物。
>
> 开始约一秒半，她安静地看着镜头，嘴唇松弛闭合。像注意到对方一个有趣的小表情，她的目光先更专注地落在镜头上，眼神带出一点笑意，嘴角随后轻轻扬起；不是突然摆出固定笑脸。
>
> 接下来约两秒半，她带着这点好奇自然靠近。动作来自上身重心向前，肩膀与头一起前移，颈部保持正常长度和舒适姿态；不是把下巴单独向前伸。原来支在腰侧的手臂随身体放松协调，不突然摆出新手势。相机始终不动，景别变近仅来自人物靠近。
>
> 在靠近的位置停留约一到两秒，目光仍与镜头交流。笑意留在眼睛和嘴角，神情俏皮而克制，嘴唇自然闭合，不刻意抿嘴、不强迫露齿，不连续歪头或点头。允许自然眨眼，不安排机械重复。
>
> 随后她缓缓把重心移回原处，肩颈一起恢复输入图中的位置；笑意温和地收回原来的平静表情。最后约一秒半维持输入图的正面姿态与人物尺度，让动作真正结束，而不是停在仍向后移动的一帧。
>
> 全程肤色、背景、曝光、白平衡和焦距稳定；人物靠近时保持原有皮肤细节，不能变成更圆的脸、另一套妆容或泛白高光。无字幕、标志、音乐和说话；导出互动版本不保留音轨。不要通过叠化、换镜头、变焦或额外转侧身完成动作。

这是下一轮试片的完整意图草案，不承诺逐秒服从或精确像素还原。生成之前还需确认输入帧、参考版本、模型参数与预算；本轮没有再次生成授权或扣费。

## 质量与证据边界

- 先原速看整个动作，再查首尾和停留区，不只挑一张漂亮的帧。
- 输出检查人物高度、眼线、肩宽、下颌、短发外轮廓和局部肤色；临近相同姿态比较，不能将转身阴影变化误判成肤色漂移。
- 同时检查生成颜色和浏览器实际解码颜色；明确色彩矩阵和范围，避免仅凭元数据或 OpenCV 单次解码下结论。
- 首尾同图并不保证瞬间切换自然。需要姿态与运动速度都接近，再检查待机→互动→待机；不能插入旧侧身动作假装过渡。
- 固定轻微色彩校正可用于已量化的小偏差；不靠脸部变形、过度锐化或逐帧自动曝光掩盖失败。
